# どてらい金融 顧客管理システム（45日勝負・仮）

闇金の店主になって45日間（11/1〜12/15）で純利を上げるコミカルな経営シミュレーション。
画面は「業務システム」そのもので、顧客台帳・カレンダー・元金表で客を管理する。

## 遊び方

`遊ぶ.command` をダブルクリックすると、ブラウザで開く（終わったら黒いウィンドウを閉じる）。
進み具合はブラウザに自動保存される。最初からやり直すときは右上の「最初から」。

- 1日の流れ：朝に客が来る → 身辺調査（30,000円）→ 条件を決めて貸す／断る → 期日の入金 → 夜に延滞客を1人だけ取り立て
- 勝ち負け：最終日（12/15）の締めのあとの純利が600,000円以上なら勝ち。資金も貸付もなくなるか、警察の目が100で負け
- 締めは11/15・11/30・12/15の3回

## 画面

| 画面 | 中身 |
|---|---|
| 本日の業務 | 純利の内訳、不渡りの予定、受付（見積もり付き）、取り立て、業務日誌、今後7日の支払い予定、要対応（不明入金） |
| 顧客台帳 | 検索・絞り込み・並べ替え。行を押すと顧客カルテ（申告／調査情報、貸付、取引履歴、メモ） |
| カレンダー | 10月〜12月を切り替え。日付を押すと、その日の入金予定者・貸付した債務者・入金者が一覧で出る。15日と月末は締め日で、不渡りの結果（見込み）が出る |
| 元金表 | 貸付ごとの元金・ジャンプ金・完済金額。行を押すと通帳形式の取引明細。損益（純利・経費の内訳・締めの記録・不渡りの予定）。不明入金（仮受金）の一覧 |

## 用語とルール

- **S**：支払いサイクル。10日サイクルは 10S。1〜30S を自由に決められる
- **ジャンプ金**：1回の期日に払う利息。元金残高 × 利率（円未満切り捨て）。10S でも10日分として計算する
- **ジャンプ**：ジャンプ金だけ入れて期日を次に送ること
- **元金を詰める**：ジャンプ金より多く入れた分で元金を減らすこと
- **完済金額**：元金残高 ＋ 未払いジャンプ金 ＋ その期日のジャンプ金
- **期日の数え方**：貸した日を1日目と数え、そのあとは決まった間隔（S−1日）で並ぶ（10日に10Sで貸すと期日は19日、次は28日）。1S は当日返済になるので翌日を期日にする
- **遅れたジャンプ**：延滞した客は、未払いのジャンプ金を満額払って初めてジャンプが成立する。次回の期日は元の予定のまま（10日が期日で5日遅れて15日にジャンプしても、次は24日ではなく19日）。取り立てで回収できるのは客がかき集めた額までで、満額に届かなければ延滞のまま
- **入金の充当**：未払いジャンプ金に先に充て、多い分で元金を詰める。内訳は「ジャンプ(80,000)＋元金詰め(149,000)」のように表示する
- **回収累計** ＝ ジャンプ金累計 ＋ 回収済元金
- **不明入金**：誰からかわからない入金。仮受金として預かり、持ち主がわかったら手動で充当する。充当の取り消し（そのあとに同じ貸付の取引がない間）と、未充当分の返金（組戻し）ができる
- **期日前の返済**：ジャンプ金以上なら次の期日の分のジャンプを先に済ませた扱い（次回の期日はその次の予定日）。ジャンプ金に満たなければ全額で元金を詰める
- **貸付総元金**：返済中・延滞・夜逃げ（不渡り未計上）の元金の合計
- **不渡り**：期日から2週間以上遅れて連絡がつかない（夜逃げした）客。毎月15日と月末の締めで不渡りにし、その元金を貸付総元金から引く。連絡がつく延滞客は何日遅れても不渡りにしない。未払いジャンプ金はもともと売上に入れていないので、不渡りに入れるのは元金だけ
- **締め**：15日と月末の1日の終わり。夜逃げしてもまだ2週間たっていない客は次の締めに持ち越す（例：11/10の期日に遅れて11/12に夜逃げ → 11/15は5日なので持ち越し、11/30で不渡り）
- **純利** ＝ 総売上 − 経費 − 不渡り。総売上は回収したジャンプ金（返ってきた元金は入れない）。経費は身辺調査費・罰金・チラシ代。不明入金は充当するまで預かり金なので入れない

## ファイル

| ファイル | 中身 |
|---|---|
| `customers.csv` | 客の台帳（1人1行・金額は万円）。書き換えると「最初から」で反映される |
| `列の説明.md` | 台帳の各列の意味 |
| `logic.js` | 計算（画面に依存しない。Node でも動く）。調整用の数字は冒頭の `CONFIG` |
| `ui.js` / `style.css` / `index.html` | 画面 |
| `遊ぶ.command` | ローカルでサーバーを立ててブラウザで開く（ブラウザに古いファイルを覚えさせない設定つき） |
