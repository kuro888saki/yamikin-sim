# どてらい金融 顧客管理システム（仮）

闇金の店主になって、決めた期間（既定は1年：2026/11/1〜2027/10/31）で純利を上げるコミカルな経営シミュレーション。
画面は「業務システム」そのもので、顧客台帳・カレンダー・元金表で客を管理する。

## 遊び方

`遊ぶ.command` をダブルクリックすると、ブラウザで開く（終わったら黒いウィンドウを閉じる）。
進み具合はブラウザに自動保存される。最初からやり直すときは右上の「最初から」。そのとき、今の顧客台帳（編集・追加した客）を引き継ぐか、`customers.csv` から読み直すかを選べる。

- 1日の流れ：朝に客が来る → 身辺調査（30,000円）→ 受付表記の5項目を入れて貸す／断る → 期日の入金 → 夜に延滞客を1人だけ取り立て
- 勝ち負け：最終日の締めのあとの純利が目標以上なら勝ち。既定は1年で目標5,000,000円。資金も貸付もなくなるか、警察の目が100で負け
- 期間と目標：右上の「期間・目標」でいつでも変えられる。最終日は締め日（15日か月末）から選ぶ。目標の標準は1日あたり13,700円 × 日数（1年で500万円、45日で60万円）
- 期間が終わって結果が出たあとも、「期間を延ばして続ける」で営業を続けられる
- 早送り：下の「早送り ▶▶」で、予定（来店・期日・締め・延滞）のない日を飛ばし、次に予定がある日まで進める。延滞客がいる間は1日ずつ進む。飛ばした日の出来事は業務日誌に日付つきで並び、その間の入金もまとめて出る

## 画面

| 画面 | 中身 |
|---|---|
| 本日の業務 | 純利の内訳、不渡りの予定、受付（見積もり付き）、取り立て、業務日誌、今後7日の支払い予定、要対応（不明入金） |
| 顧客台帳 | 検索・絞り込み・並べ替え・流入元の列。「＋ 顧客を追加」で客を増やせる。行を押すと顧客カルテ（基本情報・申告・勤務先・保証人・緊急連絡先・流入元・調査情報・貸付・取引履歴・メモ）。カルテの「編集」で中身を書き換えられ、下のボタンで削除できる |
| カレンダー | 開店前の月〜最終日の翌月を切り替え。日付を押すと、その日の入金予定者・貸付した債務者・入金者が一覧で出る。15日と月末は締め日で、不渡りの結果（見込み）が出る |
| 元金表 | 貸付ごとの元金・ジャンプ金・完済金額。行を押すと通帳形式の取引明細。損益（純利・経費の内訳・締めの記録・不渡りの予定）。不明入金（仮受金）の一覧 |

## 用語とルール

- **受付表記**：貸付条件は次の5点で決める。例：①5-6.5 ②10S ③初回11/10 ④振込金額45,000円 ⑤振込先口座
  - ① 元金-完済金（万円）：5-6.5 は元金50,000円に対して完済金65,000円、つまり利息15,000円（3割）。2-3.2 なら元金20,000円・利息12,000円
  - ② S：支払いサイクル（1〜30S）
  - ③ 初回の期日：自由に決める（明日〜最終日）。2回目からは初回から S−1日おき
  - ④ 振込金額：実際に渡す額。元金との差は振込手数料として、貸した日に売上に計上する（元金の2割まで）。50,000円の貸付で5,000円引いて45,000円振り込めば、手数料5,000円が売上
  - ⑤ 振込先口座：自由に書ける（記録用）
- **S**：支払いサイクル。10日サイクルは 10S
- **ジャンプ金**：1回の期日に払う利息。元金残高 × 利息/元金（①の比率。円未満切り捨て）。5-6.5 で元金を40,000円に詰めたら次は12,000円。10S でも10日分として計算する
- **ジャンプ**：ジャンプ金だけ入れて期日を次に送ること
- **元金を詰める**：ジャンプ金より多く入れた分で元金を減らすこと
- **完済金額**：元金残高 ＋ 未払いジャンプ金 ＋ その期日のジャンプ金
- **期日の数え方**：初回の期日は③で決める。受付では、貸した日を1日目と数えた S 日目（10日に10Sで貸すと19日）を初期値にしている。そのあとは決まった間隔（S−1日）で並ぶ（19日の次は28日）。1S は当日返済になるので間隔は1日
- **遅れたジャンプ**：延滞した客は、未払いのジャンプ金を満額払って初めてジャンプが成立する。次回の期日は元の予定のまま（10日が期日で5日遅れて15日にジャンプしても、次は24日ではなく19日）。取り立てで回収できるのは客がかき集めた額までで、満額に届かなければ延滞のまま
- **入金の充当**：未払いジャンプ金に先に充て、多い分で元金を詰める。内訳は「ジャンプ(80,000)＋元金詰め(149,000)」のように表示する
- **回収累計** ＝ ジャンプ金累計 ＋ 回収済元金
- **不明入金**：誰からかわからない入金。仮受金として預かり、持ち主がわかったら手動で充当する。充当の取り消し（そのあとに同じ貸付の取引がない間）と、未充当分の返金（組戻し）ができる
- **期日前の返済**：ジャンプ金以上なら次の期日の分のジャンプを先に済ませた扱い（次回の期日はその次の予定日）。ジャンプ金に満たなければ全額で元金を詰める
- **貸付総元金**：返済中・延滞・夜逃げ（不渡り未計上）の元金の合計
- **不渡り**：期日から2週間以上遅れて連絡がつかない（夜逃げした）客。毎月15日と月末の締めで不渡りにし、その元金を貸付総元金から引く。連絡がつく延滞客は何日遅れても不渡りにしない。未払いジャンプ金はもともと売上に入れていないので、不渡りに入れるのは元金だけ
- **締め**：15日と月末の1日の終わり。夜逃げしてもまだ2週間たっていない客は次の締めに持ち越す（例：11/10の期日に遅れて11/12に夜逃げ → 11/15は5日なので持ち越し、11/30で不渡り）
- **純利** ＝ 総売上 − 経費 − 不渡り。総売上は回収したジャンプ金＋振込手数料（返ってきた元金は入れない）。経費は身辺調査費・罰金・チラシ代。不明入金は充当するまで預かり金なので入れない
- **顧客カルテ**：次の項目を自由に書き換えられる
  - 基本情報：氏名・ふりがな・年齢・職業・現住所・実家の住所・実家の連絡先
  - 申告と希望：月収（申告）・希望額・申告した理由・担保
  - 勤務先：勤務先名・電話番号・所在地・勤務時間・休日・給料日
  - 保証人：氏名・関係・連絡先（携帯番号など）。空欄なら保証人なしで、「保証人に連絡」は使えない。「連絡がつかない」のチェックもここで変えられる
  - 緊急連絡先：3名まで（氏名・関係・連絡先）
  - 流入元：X・DM・テレアポ・紹介・チラシ・飛び込み・ネット検索・その他。紹介なら紹介者名、ほかに補足
  - 来店予定：次に来る日。今日にすると（ほかに来店中の客がいなければ）すぐ来店する。断った客も、来店予定を入れれば来る
  - ゲームの設定（本当の月収・弱み・逃げ足など、身辺調査で分かる情報）：編集画面の中で開いたときだけ見える。追加するときは「おまかせ」で自動で決められる
- **顧客の削除**：貸付が残っている客（返済中・延滞・夜逃げ）と来店中の客は削除できない。取引の記録がない客はカルテごと消える。記録がある客は台帳から外すだけで、元金表や損益の数字は残る（「削除済み」で見られ、台帳に戻せる）

## ファイル

| ファイル | 中身 |
|---|---|
| `customers.csv` | 客の台帳（1人1行・金額は万円）。書き換えると「最初から」で反映される |
| `列の説明.md` | 台帳の各列の意味 |
| `logic.js` | 計算（画面に依存しない。Node でも動く）。調整用の数字は冒頭の `CONFIG` |
| `ui.js` / `style.css` / `index.html` | 画面 |
| `遊ぶ.command` | ローカルでサーバーを立ててブラウザで開く（ブラウザに古いファイルを覚えさせない設定つき） |
